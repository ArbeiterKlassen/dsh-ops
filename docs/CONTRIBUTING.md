# Contributing

欢迎来到dsh-ops！

- dsh-ops专注践行极简主义，低侵入性，仅为dsh提供额外的易用tools，包括bash本身也使用ops_bash提供，对原版的逻辑更改仅限于可选的禁用原版重复工具，以保证和其他插件的兼容性
- pr必须关联issue，且主动在issue领取 ———— 否则不通过，这是为了以issue是否被领取来确认彼此的工作，防止重复
- issue是pr工作区，非反馈bug或者写新功能的讨论，请移步至Disscuions
- feat前请先写issue，经由维护团队批准后再写feat功能。dsh-ops团队希望保持代码和功能简洁
- dsh-ops会和一些dsh插件联动。对插件间联动层的实现单开逻辑区域，要完全和核心逻辑解耦
